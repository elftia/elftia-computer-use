# elftia-computer-use

Standalone computer-use CLI: JSON-stdout desktop perception and input automation for
shell-capable agents (Elftia TinyElf, Claude Code, Codex). Windows-first via a
zero-dependency PowerShell facade; macOS/Linux fail honestly with `ENOTSUPPORTED`.

> Skeleton — full install/usage/contract documentation lands with the final polish pass.
